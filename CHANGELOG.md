# Changes

## 1.1.0

- Teach digits 0–9 and punctuation as well as A–Z, including single Unicode punctuation/symbol labels.
- Organize Advanced into Alphabet teaching, Image settings, Matches, and About tabs.
- Recognize strongly matched disconnected punctuation, including question marks, colons, and equals signs.
- Distinguish a recognized question mark from an uncertain match in annotation color and uncertainty counts.
- Keep loading existing A–Z profiles. Profiles containing numbers or punctuation use format version 2 and require app version 1.1.0 or newer.
- Add an AI-use disclosure, local-data information, application license, and public download instructions.
- Replace the README preview with the supplied storage-sign screenshot under a new image URL.

## 1.0.0

Initial Windows and Linux portable releases, taught A–Z profiles, clipboard images, template matching, and a simplified interface with Advanced controls.
